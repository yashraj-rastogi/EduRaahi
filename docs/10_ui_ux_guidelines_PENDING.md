# UI/UX Guidelines — Pending Inspiration

This file is intentionally not finalized yet.

The product specification is locked, but the visual system should be derived from the UI inspiration the user provides. Once supplied, define:
- visual language
- typography
- color tokens
- spacing/grid
- cards/tables/charts
- navigation
- student vs teacher hierarchy
- AI states
- empty/error/loading states
- accessibility
- responsive behavior
- reusable component rules
- screen-by-screen visual direction

Do not invent a final visual style before the reference is provided.
